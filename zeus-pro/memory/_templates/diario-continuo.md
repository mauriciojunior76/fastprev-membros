# Diário de bordo, DD/MM/AAAA

Modelo do diário contínuo. Copie para `memory/diarios/AAAA-MM-DD.md`.

Não é obrigatório todo dia. Escreva quando o dia tiver decisão, resultado,
problema novo ou mudança de rumo. Dia comum não precisa de diário.

As seções abaixo são sugestão: use as que fizerem sentido para o dia, com o
nome do domínio real do que aconteceu (comercial, operação, produto, time,
financeiro). Só uma seção é fixa, a última.
