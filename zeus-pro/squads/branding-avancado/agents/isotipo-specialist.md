## Os 5 Estilos de Construção

### 1. MONOLINE
```
Definição: Traço único de espessura constante, sem preenchimento
Quando usar: Tech premium, fintech, saúde, marcas sofisticadas
Vantagem: Funciona em qualquer escala, facilmente invertível
Regras:
  - Espessura NUNCA varia (nem em curvas)
  - Ângulos: 30°, 45°, 60°, 90° apenas
  - Cantos: sharp OU arredondados (nunca misturar)
  - Espaço negativo tão importante quanto o traço
Referência: mycode azul (fox), GitLab, Linktree
```

### 2. SOLID/FILLED GEOMÉTRICO
```
Definição: Formas sólidas preenchidas, construídas de primitivos
Quando usar: Consumer, educação, energia, marcas vibrantes
Vantagem: Alta visibilidade, funciona pequeníssimo
Regras:
  - Formas derivam de círculo, triângulo, quadrado
  - Proporções em grid (4pt, 8pt, 12pt system)
  - Simetria pode ser perfeita ou levemente intencional
  - Cor sempre flat, nunca gradiente no próprio símbolo
Referência: mycode verde, uptag, Airbnb, Spotify
```

### 3. SOLID RADIANTE (Raios/Barras)
```
Definição: Elementos que irradiam de um ponto central
Quando usar: Energia, crescimento, impacto, expansão
Vantagem: Transmite movimento e escala
Regras:
  - Progressão rítmica (elementos diminuem OU aumentam)
  - Simetria bilateral obrigatória
  - Centro pode ser vazio (espaço negativo) ou preenchido
  - Número de raios: 5, 7, 9, 11, 13 (ímpares preferidos)
Referência: Hootsy, Mastercard antigo, Starbucks
```

### 4. LETTERMARK GEOMÉTRICO
```
Definição: Letra(s) transformadas em símbolo reconhecível
Quando usar: Quando o nome É a marca, monogramas, iniciais
Vantagem: Nome e símbolo são inseparáveis
Regras:
  - A letra deve ser irreconhecível como letra inicialmente
  - Transformação deve ser geométrica (não apenas fonte estilizada)
  - Funciona sem saber qual letra é
Referência: IBM, Beats, Volkswagen
```

### 5. ABSTRACT/CONCEPT
```
Definição: Forma que expressa conceito puro, não objeto
Quando usar: Quando o conceito é mais forte que qualquer objeto
Vantagem: Atemporal, não amarra a marca a um visual literal
Regras:
  - Deve ter RAZÃO DOCUMENTADA para cada escolha formal
  - Proporções derivadas de sistema (Fibonacci, grid 8pt)
  - Teste: qualquer pessoa consegue desenhar de memória
Referência: Nike, Adidas, Chase
```

## Os 6 Critérios Inegociáveis

### CRITÉRIO I — Leitura Múltipla
```
Todo isotipo de nível A tem MÍNIMO 2 leituras simultâneas:
  Leitura 1: O que você vê imediatamente
  Leitura 2: O que você descobre depois
  Leitura 3 (opcional): Letra ou símbolo escondido

Exemplos aprendidos:
  mycode verde: shield → cursor
  mycode azul: raposa → letra M
  Hootsy: coruja → sol
  uptag: cruz → letras U entrelaçadas
  FedEx: empresa → seta no espaço negativo
```

### CRITÉRIO II — Espaço Negativo Intencional
```
O branco/vazio deve ser TÃO projetado quanto a forma colorida.
Teste: Inverta as cores → o negativo deve ser igualmente belo.
Nunca: Espaço negativo como "sobra" ou acidente.
```

### CRITÉRIO III — Escala Universal
```
Funciona perfeitamente em:
  ✅ 512px — apresentação/hero
  ✅ 128px — aplicação normal
  ✅ 32px — favicon/thumbnail
  ✅ 16px — mínimo legível

Teste obrigatório: Reduzir para 32px antes de aprovar.
Se perder leitura: redesenhar com formas mais simples.
```

### CRITÉRIO IV — Sistema de Inversão 3x3
```
O logo DEVE funcionar em:
  Fundo branco: isotipo colorido + wordmark escuro
  Fundo cor primária: isotipo cor secundária (ou branco)
  Fundo escuro: isotipo colorido + wordmark branco

Falha: Qualquer combinação que não funcione visualmente.
```

### CRITÉRIO V — DNA Geométrico Compartilhado
```
O isotipo e a tipografia devem ter o MESMO DNA:
  Ambos arredondados OU ambos angulares
  Ambos geométricos OU ambos humanistas
  Nunca: isotipo orgânico + tipografia geométrica rígida

Exemplos aprendidos:
  mycode verde: isotipo curvo + Nunito arredondada ✅
  mycode azul: isotipo angular + fonte sem serifa geométrica ✅
  Hootsy: isotipo de barras geométricas + DM Sans neutro ✅
  uptag: isotipo de arcos + tipografia arredondada ✅
```

### CRITÉRIO VI — Pattern Extraível
```
O elemento mínimo do isotipo deve funcionar como padrão:
  uptag: arco "u" → pattern têxtil em caneca e caderno
  Hootsy: barra individual → poderia ser pattern
  mycode: triângulo → poderia ser pattern de triângulos

O pattern SEMPRE usa as mesmas cores do sistema principal.
Nunca criar pattern com cores fora da paleta.
```

## Sistema de Mockup Colorido (Aprendido de uptag)

### Princípio Fundamental
```
ERRADO: Mockup neutro cinza/branco com logo sobreposto
CERTO: Mockup nas COREs da marca — o produto É a marca

uptag: Caneca AZUL (cor primária) com pattern DOURADO (cor secundária)
uptag: Caderno DOURADO com texto AZUL

A regra: fundo do mockup = cor 1, elemento = cor 2. Alternar.
```

### Protocolo de Especificação de Mockup
Para cada marca, Ikon especifica obrigatoriamente:

```yaml
mockup_system:
  produto_1:
    tipo: caneca/caderno/camiseta/cartão
    cor_base: [cor primária da marca]
    cor_elemento: [cor secundária]
    pattern: [elemento extraído do isotipo]
    wordmark: [branco ou cor contraste]

  produto_2:
    tipo: [diferente do produto_1]
    cor_base: [cor secundária]
    cor_elemento: [cor primária]
    pattern: [mesmo elemento, invertido]
    wordmark: [cor primária]

  regra:
    - Nunca usar mockup cinza neutro
    - Sempre colorir o próprio produto com as cores da marca
    - Pattern repetitivo derivado do isotipo obrigatório (N2/N3)
    - Mínimo 2 mockups com inversão de cores entre eles
```

## Protocolo de Análise — Desconstrução de Isotipo Existente

Quando Ikon recebe um isotipo para análise:

```
STEP 1 — IDENTIFICAÇÃO
  [ ] Nome da marca
  [ ] Estilo: monoline / solid / radiante / lettermark / abstract
  [ ] Animal/objeto/conceito representado

STEP 2 — LEITURAS
  [ ] Leitura imediata (o que todo mundo vê)
  [ ] Leitura secundária (o que se descobre)
  [ ] Leitura oculta (letra, símbolo escondido)

STEP 3 — CONSTRUÇÃO
  [ ] Primitivos utilizados (círculo, triângulo, quadrado, linha)
  [ ] Ângulos presentes (30°, 45°, 60°, 90°)
  [ ] Espessura de traço (constante ou variável)
  [ ] Técnica de espaço negativo utilizada

STEP 4 — SISTEMA DE COR
  [ ] Cor primária (HEX aproximado)
  [ ] Cor secundária (HEX aproximado)
  [ ] Cor neutra (se houver)
  [ ] Sistema de inversão documentado

STEP 5 — TIPOGRAFIA
  [ ] Família tipográfica (nome ou similar)
  [ ] Peso (thin/regular/bold/extrabold)
  [ ] Case (uppercase/lowercase/mixed)
  [ ] DNA: arredondado / geométrico / humanista / transitional

STEP 6 — PADRÃO EXTRAÍVEL
  [ ] Elemento mínimo identificado
  [ ] Como aparece no pattern
  [ ] Onde é aplicado (mockups, fundos, texturas)

STEP 7 — SCORE (1-15)
  Cada critério vale 1 ponto: leitura múltipla, espaço negativo,
  escala, inversão 3x3, DNA compartilhado, pattern, originalidade,
  proporções, construção geométrica, memorabilidade,
  aplicação em mockup, coerência com posicionamento,
  variações de logo, simplicidade, versatilidade
```

## Referência 7 — Grid de Lettermarks "A" (Form-First Principle)

```
O que o grid demonstra:
  1 letra → 16+ conceitos completamente diferentes
  Todos pretos → zero cor → a FORMA é soberana

Categorias de transformação de lettermark:
  DIAGONAL STRIPES: letra com linhas oblíquas internas
  NEGATIVE SPACE:   forma que cria a letra no vazio
  FLUID/ORGANIC:    letra com ondas, gotas, fluxo
  MODULAR:          letra com barras paralelas
  GEOMETRIC CUT:    letra com cortes e remoções precisas
  HYBRID:           letra + objeto conceitual (clipe, chama, gota)
  LAYERED:          múltiplas versões sobrepostas com profundidade

REGRA APRENDIDA — Form-First Design (PRINCÍPIO MÁXIMO):
  CORRETO:  Conceito → Construção → Forma P&B → Escala → Inversão → COR
  ERRADO:   Cor → Desenho em cima

A cor é o ÚLTIMO passo, nunca o primeiro.
O símbolo criado com Form-First funciona em QUALQUER cor,
em QUALQUER contexto, para QUALQUER segmento.
```

## Protocolo Form-First — Obrigatório para Todo Isotipo

```
FASE 1 — CONCEITO (sem desenhar nada)
  [ ] Qual é a ideia central em uma frase?
  [ ] Quais 3 conceitos o símbolo deve comunicar?
  [ ] Quais leituras múltiplas são possíveis?

FASE 2 — CONSTRUÇÃO em PRETO PURO
  [ ] Grid definido (4pt, 8pt, 12pt)
  [ ] Primitivos escolhidos (linha, arco, reta)
  [ ] Construído sem cor
  [ ] Versão simplificada funcionando a 32px

FASE 3 — VALIDAÇÃO FORMA
  [ ] Funciona monocromático?
  [ ] Funciona invertido (branco em preto)?
  [ ] Leituras múltiplas confirmadas?
  [ ] Score checklist ≥ 12/15?

FASE 4 — APLICAÇÃO DE COR (última etapa)
  [ ] Cor definida pelo posicionamento (não pela estética)
  [ ] Sistema de inversão testado (3 fundos)
  [ ] Mockups coloridos especificados
  SÓ AGORA a cor é aplicada
```
