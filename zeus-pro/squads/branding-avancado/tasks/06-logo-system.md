## Tipos de Marca Gráfica — Referência

| Tipo | Descrição | Quando usar |
|------|-----------|-------------|
| **Wordmark** | Apenas tipografia | Nome curto, forte e único — diferenciação tipográfica |
| **Lettermark** | Iniciais | Nomes longos ou siglas com reconhecimento |
| **Symbol/Ícone** | Apenas símbolo | Marcas estabelecidas ou quando o símbolo é o conceito |
| **Combination mark** | Símbolo + wordmark | Mais comum — flexível e completo |
| **Emblem** | Integrado em forma fechada | Tradição, comunidade, premium hereditário |
| **Dynamic mark** | Sistema variável | Marcas culturais, eventos, plataformas criativas |

## Protocolo de Execução

```
STEP 1: Analisar direção visual e conceito central
        → Qual é o conceito visual central de Veda?
        → Qual é o universo estético (O que é / O que nunca é)?
        → Quais são as instruções específicas de Veda para Mark?

STEP 2: Definir tipo de marca gráfica
        → Qual tipo serve melhor ao arquétipo e à estratégia?
        → Justificar a escolha com base em:
           → Nome (comprimento, sonoridade, unicidade)
           → Mercado (o que concorrentes usam — fazer diferente)
           → Uso previsto (digital first? impresso? ambos?)
           → Nível de reconhecimento atual da marca

STEP 3: Construir racional conceitual do símbolo
        → Se tem símbolo: qual forma geométrica ou conceito gera o ícone?
        → O símbolo deve conectar: forma → arquétipo → estratégia
        → Formato: "O símbolo é [forma/conceito] porque [conexão com arquétipo]
          e representa [conexão com estratégia/promessa]"
        → Documentar o processo de destilação: da ideia à forma final

STEP 4: Especificar construção lógica e geométrica
        → Se tem símbolo: grade de construção
        → Proporções e relações geométricas (ângulos, raios, proporções áureas se aplicável)
        → Número de versões no sistema (mínimo 4)
        → Relação wordmark–símbolo (proporcional, alinhamento)

STEP 5: Definir tipografia do logotipo (se wordmark ou combination mark)
        → Não necessariamente a mesma da identidade de texto
        → Pode ser customizada, modificada ou licenciada
        → Justificar escolha tipográfica no contexto do logo

STEP 6: Documentar variações do sistema (mínimo 4)
        → Versão principal (combination mark ou definição central)
        → Versão horizontal
        → Versão vertical (se aplicável)
        → Versão símbolo/ícone (para uso isolado)
        → Versão negativa (branco em fundo escuro)
        → Versão monocromática
        → Versão favicon/app icon (mínimo tamanho)

STEP 7: Definir área de respiro e tamanho mínimo
        → Área de respiro: expressa como múltiplo relativo (ex: "1x a altura do símbolo")
        → Tamanho mínimo: digital (px) e impresso (mm)

STEP 8: Listar restrições absolutas (mínimo 6)
        → O que nunca fazer com o logo
        → Com exemplos de contexto específico (não apenas "não deformar")
```

## Critérios de Qualidade

| Critério | Regra | Verificação |

| Mínimo 6 restrições específicas | Com contexto — não apenas "não deformar" | Contagem e especificidade |
| Tipografia do logo tem licença documentada | Nome da licença e URL de download | Licença presente? |

| Tipo de marca gráfica tem justificativa dupla | Estratégia + mercado | Duas razões dadas? |

## Restrições Absolutas — Exemplos de Referência

(Exemplos de como construir restrições específicas — não copiar literalmente)

1. "Não aplicar o logo sobre fotografias com textura intensa — contraste insuficiente e perda de legibilidade"
2. "Não usar a versão principal em tamanhos abaixo de 80px — o símbolo perde definição"
3. "Não recriar o logo em fontes do sistema (Arial, Times, Helvetica) — a geometria é proprietária"
4. "Não inverter as cores internas do símbolo — a hierarquia visual é intencional"
5. "Não usar o símbolo isolado em contextos de primeira impressão — a marca não tem reconhecimento ainda"
6. "Não aplicar sombra ou efeito de profundidade — a marca é plana por princípio"
