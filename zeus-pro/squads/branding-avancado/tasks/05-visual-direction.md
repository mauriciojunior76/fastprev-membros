## Princípio Fundamental

A direção visual não é sobre preferência estética — é sobre coerência estratégica. Cada decisão visual deve ser rastreável ao arquétipo, à estratégia ou ao ICP. Decisões sem justificativa estratégica são decoração, não identidade.

---

## Protocolo de Execução

```
STEP 1: Absorver estratégia, arquétipo e voz
        → Qual é a tensão que a marca resolve? (Sage)
        → Qual é o arquétipo primário e secundário? (Mira)
        → Qual é o tom de voz e as dimensões? (Lexi)
        → Quais são as palavras que a marca DEVE e NUNCA transmitir? (Briefing)

STEP 2: Identificar universo visual coerente com o arquétipo
        → Cada arquétipo tem campos visuais naturais:
           Herói → tensão, contraste, dinamismo
           Mago → profundidade, transformação, mistério
           Sábio → estrutura, clareza, precisão
           Criador → originalidade, texturas, processo visível
           Governante → ordem, proporção áurea, autoridade
           Amante → sensorialidade, calor, proximidade
        → Identificar o campo visual primário desta marca

STEP 3: Definir conceito visual central (1 ideia geradora)
        → 1 frase com metáfora específica que gera todo o sistema visual
        → Formato: "A identidade visual de [marca] é como [metáfora específica]
          — [o que isso implica visualmente]"
        → Teste: consegue-se derivar decisões de cor, forma e tipografia dessa frase?

STEP 4: Construir moodboard verbal (10–15 elementos)
        → Não adjetivos comuns — referências específicas de cultura visual
        → Mistura de: movimentos artísticos, períodos históricos, materiais físicos,
          sensações sensoriais não-visuais, campos culturais
        → Ex: "arquitetura brutalista japonesa dos anos 70", "couro envelhecido com costura à mão",
          "o silêncio de uma biblioteca de madrugada"

STEP 5: Definir direção de arte em 4 dimensões
        → Peso visual: leve ←——→ denso
        → Temperatura: fria ←——→ quente
        → Ritmo: estático ←——→ dinâmico
        → Profundidade: plana ←——→ tridimensional
        → Para cada dimensão: posição + justificativa + implicação prática

STEP 6: Documentar O QUE É e O QUE NUNCA É
        → O que é: 5–8 elementos visuais que definem o universo
        → O que nunca é: 5–8 proibições específicas com motivo
        → Proibições devem ser específicas (não "sem gradientes")

STEP 7: Definir sensação dominante e referências informadoras
        → Sensação dominante: o estado emocional ao ver a marca pela primeira vez
        → Referências informadoras: 5–8 referências visuais com descrição do que extrair
          (não "a cor do Instagram" — "a paleta de azuis do Instagram Stories em 2019")

STEP 8: Documentar em visual-direction.md com instruções para Mark, Chroma e Typo
```

## Critérios de Qualidade

| Critério | Regra | Verificação |
|----------|-------|-------------|
| Conceito visual central é 1 frase com metáfora | Específica o suficiente para derivar decisões práticas | Consegue-se derivar cor e forma? |
| Moodboard tem 10+ elementos distintos | Não apenas adjetivos — referências culturais específicas | Contagem e especificidade |
| Proibições são específicas | Não "sem gradientes" — "sem gradientes de 3+ cores em fundo branco" | Cada proibição tem contexto |
| Referências têm aspecto específico | "o que extrair" é preciso — não "estética geral" | Coluna preenchida? |
| 4 dimensões têm posição E justificativa | Número + razão estratégica por dimensão | Ambas preenchidas? |
| Instruções por agente são acionáveis | Mark, Chroma e Typo sabem exatamente o que fazer | Instruções específicas? |
| Sensação dominante é verificável | Alguém externo consegue confirmar ao ver a marca? | Teste com terceiro |

---

## Erros Comuns a Evitar

- Conceito visual central genérico ("elegante e moderno")
- Moodboard com apenas adjetivos ("limpo", "premium", "ousado")
- Proibições vagas ("sem fontes velhas", "sem cores feias")
- Referências sem extração específica ("como a Apple")
- Não entregar instruções para Mark, Chroma e Typo
