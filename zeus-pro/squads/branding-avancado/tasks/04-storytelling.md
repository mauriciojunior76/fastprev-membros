## Por Que Storytelling É Fase 1 (Não Fase 3)

A narrativa de marca não é decoração — é estrutura. O manifesto define:
- A tensão que a marca resolve
- Por que a marca existe (não o que ela vende)
- A crença que polariza (quem concorda vira cliente; quem discorda é o anti-público)

Sem narrativa clara, o sistema visual não tem alma.

## Protocolo de Execução

```
STEP 1: Absorver estratégia, arquétipo e tom de voz
        → Qual é a tensão central da marca? (o problema que ela resolve no mundo)
        → Qual é a crença que a marca defende que não é óbvia?
        → Qual é o arquétipo e como ele afeta o modo de narrar?

STEP 2: Escrever o manifesto (150–250 palavras)
        → Estrutura obrigatória:
           → Abertura: tensão real (o problema existe, tem nome)
           → Desenvolvimento: por que o status quo é insuficiente
           → Virada: o que a marca acredita que muda isso
           → Fechamento: convite — não CTA de vendas
        → Tom: deve polarizar. Quem lê ou concorda completamente ou discorda.
        → Proibido: não começar com "Acreditamos que...", não terminar com "Junte-se a nós"

STEP 3: Escrever origem da marca (por que existe, não como surgiu)
        → Foco na tensão que levou à criação
        → Não é linha do tempo — é propósito
        → Máx 150 palavras

STEP 4: Definir visão e missão (inspiradores mas específicos)
        → Visão: onde o mundo chega se a marca vencer
        → Missão: o que a marca faz todo dia para chegar lá
        → Formato: 1 frase cada — específicas o suficiente para excluir empresas semelhantes

STEP 5: Articular crença central (1 frase que polariza)
        → Formato: "Acreditamos que [afirmação que divide opiniões]"
        → Teste: se 80% das pessoas concordarem facilmente, a crença é genérica

STEP 6: Criar narrativa curta (50 palavras)
        → Para redes sociais, bio, apresentação
        → Contém: quem é, o que acredita, o que faz, para quem

STEP 7: Criar narrativa expandida (250–400 palavras)
        → Para About page, apresentações formais
        → Inclui: contexto, tensão, crença, diferença, convite

STEP 8: Escrever 10 headlines institucionais distintos
        → Para diferentes contextos: anúncio, bio, hero section, palestra, press kit
        → 10 genuinamente diferentes — não variações da mesma frase
        → Mix de: provocativos, afirmativos, questionadores, paradoxais

STEP 9: Criar 5–8 frases de impacto
        → Funcionam sem contexto — qualquer pessoa entende
        → São compartilháveis como citações
        → Variam em estrutura gramatical
```

## Critérios de Qualidade

| Critério | Regra | Verificação |
|----------|-------|-------------|
| Manifesto tem tensão real | Começa com problema — não com visão positiva genérica | Primeira frase é tensão? |
| Crença central polariza | Se 80% concordam facilmente, é genérica | Teste de polarização |
| 10 headlines genuinamente diferentes | Não são variações da mesma ideia | Tipos distintos listados? |
| Frases de impacto funcionam sem contexto | Qualquer pessoa entende sem saber da marca | Teste de isolamento |
| Manifesto não começa com "Acreditamos" | Clichê de manifesto corporativo | Verificar abertura |
| Manifesto não termina com "Junte-se a nós" | Clichê de CTA genérico | Verificar fechamento |
| Narrativa curta tem exatamente ~50 palavras | Contagem feita | Contagem verificada |
| Narrativa expandida tem 250–400 palavras | Não muito curta, não muito longa | Contagem verificada |

## Regras de Escrita de Manifesto

**O manifesto DEVE:**
- Nomear o problema de forma que o ICP se reconheça imediatamente
- Tomar partido — não ser neutro
- Usar segunda pessoa (você/sua) pelo menos uma vez
- Ter ritmo — frases curtas e longas alternando
- Terminar com sensação de possibilidade, não de CTA

**O manifesto NUNCA deve:**
- Usar: "inovação", "disrupção", "mundo melhor", "próximo nível", "transformar vidas"
- Prometer resultados sem base
- Soar como visão de empresa de tecnologia genérica
- Ser mais longo que 250 palavras
