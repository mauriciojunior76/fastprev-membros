## Protocolo de Execução

```
STEP 1: Ler briefing expandido e hipótese de arquétipo de Zeus
        → Qual arquétipo Zeus sugeriu?
        → Quais são as palavras que a marca DEVE transmitir?
        → Qual é a transformação prometida?

STEP 2: Analisar ICP e anti-público de Sage (se disponível)
        → Com quais arquétipos o ICP se identifica?
        → Qual arquétipo o anti-público espera? (para diferenciar)
        → Qual é a crença central do ICP?

STEP 3: Mapear arquétipo primário
        → Testar os 12 arquétipos contra os dados
        → Selecionar 1 com justificativa estratégica (não apenas emocional)
        → Documentar por que os outros foram descartados

STEP 4: Mapear arquétipo secundário (influência de 20–30%)
        → Qual arquétipo complementa o primário sem contradizê-lo?
        → Como a mistura cria uma identidade única?
        → Documentar a tensão criativa entre os dois

STEP 5: Definir sombra (o que a marca nunca é)
        → Sombra não é o oposto do primário — é seu excesso patológico
        → Herói sem sombra → Arrogante / Ditador
        → Mago sem sombra → Manipulador / Charlatão
        → Documentar a sombra e como a marca a evita ativamente

STEP 6: Derivar 5 traços de personalidade com comportamentos
        → Cada traço: substantivo + adjetivo qualificador
        → Cada traço tem: definição + 2 exemplos de comportamento concreto
        → Exemplos são situações reais (post de rede social, email, pitch, atendimento)

STEP 7: Definir tom psicológico em 3 momentos diferentes
        → Momento 1: A marca está celebrando uma vitória do cliente
        → Momento 2: A marca está entregando feedback difícil
        → Momento 3: A marca está respondendo a uma crítica pública

STEP 8: Documentar em archetypes.md
        → Seguir estrutura de output abaixo
        → Verificar critérios de qualidade antes de finalizar
```

## Critérios de Qualidade

| Critério | Regra | Verificação |
|----------|-------|-------------|
| Combinação arquétipo é única | Não usar "Herói+Criador" ou "Mago+Sábio" sem justificativa diferenciada | É diferente dos concorrentes? |
| Cada traço tem comportamento concreto | Não "é autêntico" — é "responde comentários negativos com dados, não com defesa" | 2 exemplos por traço |
| Tom de voz verificável nos 3 momentos | Diferente em cada momento — não genérico | São realmente diferentes? |
| Sombra é o excesso, não o oposto | Herói → Arrogante (não Covarde) | Está correto? |
| Metáfora de energia tem especificidade | Não "é como uma luz" — tem contexto e relação | Tem sujeito + verbo? |
| Tabela É/Nunca É tem 5 linhas | Com pares reais — não óbvios | Preenchida? |

## Arquétipos Proibidos como Primário (sem justificativa sólida)

As seguintes combinações são excessivamente comuns no mercado e devem ser evitadas salvo justificativa estratégica muito clara:

- Herói + Criador (startup de tecnologia genérica)
- Mago + Inocente (wellness/saúde sem propósito)
- Sábio + Governante (consultoria genérica)

Se Zeus sugeriu uma dessas combinações, Mira deve questionar e propor alternativas.
