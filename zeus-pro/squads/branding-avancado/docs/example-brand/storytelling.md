## Taglines — 3 Opções Testadas

### Opção A — "Dados que não mentem."
**Idioma:** Português direto
**Estrutura:** Declaração. Período curto. Zero adjetivo.
**Tensão:** Implica que o que você usa hoje pode mentir — sem dizer isso.
**Memorabilidade:** Alta — inverte a expectativa ("dados sempre mentem" é um medo real de gestores)
**Rationale:** Funciona sozinha. Funciona depois do logo. Funciona em inglês como "Data that doesn't lie." Sem tradução forçada.

**STATUS: ESCOLHIDA**

---

### Opção B — "Precisão sem compromisso."
**Idioma:** Português neutro
**Estrutura:** Substantivo + negação
**Tensão:** Posiciona contra o mercado que "compromise" qualidade por UX
**Memorabilidade:** Média — soa bem mas não é singular
**Rationale:** Descartada — "sem compromisso" virou clichê em tech. Perde autenticidade.

---

### Opção C — "O eixo da sua decisão."
**Idioma:** Português com jogo de marca
**Estrutura:** Metáfora geométrica + posse
**Tensão:** Posiciona AXIS como infraestrutura essencial
**Memorabilidade:** Alta, mas dependente de visual — fraca em áudio/texto isolado
**Rationale:** Excelente como tagline de campanha, fraca como tagline mestra. Reservar para uso secundário.

## Tagline Escolhida — Justificação Completa

### "Dados que não mentem."

**Por que funciona para o ICP:**

O gestor de fundo com R$500M+ AUM tem um medo específico e não confessado: que o dado que ele está vendo pode estar errado. Não por acidente — mas por design do sistema. Arredondamentos. Atrasos de latência apresentados como "tempo real". APIs que falham silenciosamente e retornam o último valor conhecido. O mercado sabe que isso acontece. AXIS nomeia o medo sem precisar explicar.

**Tensão implícita:**
A tagline não acusa concorrentes. Cria uma pergunta na cabeça do prospect: "O meu sistema atual mente?" Se a resposta for "talvez", AXIS ganhou a conversa.

**Estrutura linguística:**
- Sujeito + predicado. Não tem adjetivo. Não tem exclamação.
- "Dados" — plural, material, concreto
- "que não mentem" — negação ativa, não passiva ("que são precisos" seria fraco)

**Versatilidade de aplicação:**
- Logo signature: `AXIS — Dados que não mentem.`
- Deck cover: linha isolada abaixo do logo
- Ad headline: standalone
- Email signature: após nome e cargo
- LinkedIn bio: última linha do About

**Versão em inglês (para expansão):**
`Data that doesn't lie.` — mantém a estrutura e a tensão.

## 3 Brand Stories

### Story 1 — Fundador: A Origem da Intolerância

**Título:** "O dia em que 0,3% foi demais"

Em 2019, durante a gestão de um fundo multimercado de R$800M, Rafael Camargo descobriu uma divergência de 0,3% entre os dados apresentados pelo sistema analítico da casa e os dados brutos da B3. Eram R$2,4 milhões de diferença — não por fraude, mas por latência de atualização que o sistema apresentava como tempo real.

Ninguém havia percebido. O sistema tinha uma interface limpa, um dashboard bonito, alertas coloridos. E estava mentindo com elegância.

Rafael passou os seis meses seguintes construindo um pipeline de dados que nunca arredondava, nunca estimava e nunca apresentava dado antigo como atual. Seus pares começaram a pedir acesso.

AXIS nasceu da convicção de que o dado correto não é uma feature — é o mínimo que um gestor profissional pode exigir.

*Uso: Página About, deck investidor, primeira conversa comercial*

---

### Story 2 — Transformação: Do Cheiro de Fumaça à Certeza

**Título:** "Como a Gestora Vértice parou de operar com estimativas"

A Gestora Vértice gerenciava R$1,2B em multimercado com três ferramentas diferentes para dados de renda fixa, renda variável e derivativos. A consolidação era feita em Excel, manualmente, toda manhã às 6h.

O CFO descreveu o processo como "pilotar avião com indicadores de fumaça — você sente que está indo na direção certa, mas não tem certeza de nada."

Após três meses com AXIS, o processo matinal de consolidação foi eliminado. Não foi otimizado — foi eliminado. Os dados de todas as classes de ativos passaram a ser consolidados em tempo real, com divergência máxima de 0,001% em relação às fontes primárias.

A equipe de análise, antes ocupada com conciliação manual, passou a trabalhar em modelagem prospectiva.

O CFO da Vértice: "Hoje eu sei o que tenho. Antes eu estimava."

*Uso: Case de sucesso, proposta comercial, webinar*

---

### Story 3 — Categoria: O Problema que o Mercado Normalizou

**Título:** "Por que o setor de gestão aceitou dados imprecisos como padrão"

Existe uma conversa que gestores de fundo têm entre si mas raramente têm com fornecedores de tecnologia: os sistemas que usam para tomar decisões de milhões de reais foram construídos para impressionar comitês, não para ancorar posições.

As interfaces são limpas. Os relatórios são automáticos. Os dashboards têm cores que indicam saúde do portfólio.

Mas por baixo, há uma camada de simplificação que o setor normalizou: dados apresentados como "ao vivo" com 15 minutos de atraso. Métricas de risco calculadas com modelos de 2008. Consolidações que fazem aproximações que nunca aparecem no rodapé.

AXIS não corrigiu o mercado. Recusou participar do problema.

Construída por gestores, para gestores que chegaram ao limite da tolerância com a ficção bem embalada. Uma plataforma que tem como primeira funcionalidade a honestidade do dado — e como segunda, tudo mais.

*Uso: Thought leadership, LinkedIn, artigo de imprensa*

## Messaging Framework

### Elevator Pitch — 30 segundos

> "AXIS é uma plataforma de analytics financeiro para gestoras de fundos que não toleram dado impreciso. A maioria dos sistemas do mercado simplifica dados para parecer mais limpo — AXIS não arredonda, não estima e não apresenta dado antigo como atual. Para gestores que decidem posições de R$50M+ baseados em números, a diferença entre um sistema que aproxima e um que calcula é a diferença entre certeza e exposição. **Quando usar:** Networking, evento, conversa casual com prospect

### Investor Pitch — 2 minutos

> "O mercado de analytics financeiro no Brasil movimenta R$2B ao ano. Noventa por cento desse mercado é dominado por três sistemas que foram construídos entre 1990 e 2005 e nunca foram refatorados — apenas atualizados com interfaces mais modernas sobre infraestrutura datada.

> O problema que nenhum desses sistemas resolve: dado impreciso apresentado com confiança. Latência mascarada. Arredondamento silencioso. APIs que falham sem alertar.

> Gestores de fundo sabem disso. Aceitam porque não havia alternativa real.

> AXIS é a alternativa real. Arquitetura construída do zero para dado financeiro de alta frequência. Latência máxima de 50ms em dados de mercado. Zero arredondamento — se o dado não está disponível, o sistema avisa; não inventa.

> Nosso ICP é gestor de fundo multimercado com R$500M a R$5B AUM. Um segmento de 340 gestoras no Brasil, ticket médio de R$180K/ano por cliente.

> Temos três gestoras em produção, dois LOIs assinados e pipeline de R$2,1M para os próximos 12 meses."

**Quando usar:** Reunião com VC, pitch day, reunião de follow-up com investidor

### Cold Email Opening — Primeira linha

**Versão A — Dado como anzol:**
> "A divergência média entre sistemas analíticos e dados primários de mercado no Brasil é de 0,12% a 0,4% — dentro do seu AUM, isso é quanto?"

**Versão B — Dor silenciosa:**
> "Uma pergunta direta: seu sistema atual apresenta dados como 'tempo real' com latência de quanto?"

**Versão C — Credencial:**
> "Três gestoras com R$1B+ AUM passaram os últimos seis meses eliminando consolidação manual de dados — aqui está o que mudou na operação delas."

**Quando usar:** Prospecção outbound para CFOs e sócios de gestora. Versão A para CTOs técnicos. Versão B para sócios que já sentiram a dor. Versão C para warm referral.

## Vocabulário AXIS

### Palavras QUE EXISTEM no universo AXIS (usar sempre)

| Palavra | Contexto de Uso |
|---------|----------------|
| **Precisão** | Qualidade do dado, não do design |
| **Ancoragem** | Decisão baseada em dado real — "ancoragem decisória" |
| **Topografia** | Metáfora visual dos dados como paisagem de poder |
| **Certeza** | O que o gestor tem — o oposto de estimativa |
| **Posição** | Ativo em portfólio — nunca "investimento" ou "aplicação" |
| **Convergência** | Dados alinhados entre fontes — o estado ideal |
| **Latência** | Atraso real em dados — sempre declarado, nunca escondido |
| **Profundidade** | Volume e granularidade de dados disponíveis |
| **Rigor** | Qualidade metodológica — de quem fez CFA e PhD |
| **Divergência** | O problema que o mercado ignora — AXIS nomeia |

### Palavras que NUNCA existem no universo AXIS (banidas)

| Palavra | Por Que É Banida |
|---------|-----------------|
| **Simplificado** | Contradiz o posicionamento central |
| **Fácil** | O ICP não quer fácil — quer correto |
| **Intuitivo** | Patronizador para quem tem PhD em finanças |
| **Revolucionário** | Hipérbole sem substância — o gestor vai ignorar |
| **Inovador** | Clichê de startup — AXIS não é startup, é infraestrutura |
| **Poderoso** | Genérico — todo sistema se diz poderoso |
| **Inteligência artificial** | Sem contexto técnico preciso, soa como buzzword |
| **Democratizar** | AXIS não democratiza — AXIS aprofunda para quem já está no nível |
| **Jornada** | Linguagem de UX de consumidor — não de gestora de fundo |
| **Ecossistema** | Vago e sobreusado em tech — preferir "plataforma" ou "stack" |
