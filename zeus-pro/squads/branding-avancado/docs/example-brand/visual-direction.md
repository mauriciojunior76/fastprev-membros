# Direção Visual — AXIS
**Agente:** Veda (visual-identity)

## Conceito Visual Central

**"Dados como topografia de poder"**

O visual de AXIS traduz dados financeiros em uma forma de mapa tridimensional — onde altitude representa magnitude, densidade representa certeza e profundidade representa risco. A estética não é de "dashboard de startup" — é de sala de guerra de um general de mercado. Linhas de dados como curvas de nível de um terreno que o gestor navega com domínio absoluto.

## Sensação Dominante

**Controle absoluto em ambiente de alta complexidade.**
Como um piloto de caça que vê o campo de batalha completo sem entrar em pânico — informação total, clareza total, ação precisa.

## Moodboard Verbal

profundidade sem fundo · linhas de luz em escuridão · precisão de bisturi · atlas de dados · escuro e claro sem meio-termo · peso de decisões de bilhões · silêncio antes da ação · instrumento de precisão · oceano profundo visível · topografia de mercado · ouro sobre pedra escura · clareza cortante · minimalismo que carrega gravidade · sala de operações de alto comando

## Direção de Arte — 4 Dimensões

**Peso:** Pesado — tipografia bold, backgrounds dark, elementos com massa visual. Nada é leve ou "airoso". A marca carrega peso porque os dados que representa têm peso real.

**Temperatura:** Fria a neutra — azuis profundos, grafites, branco frio. O ouro é a única fonte de calor — um acento preciso, nunca dominante. A frieza não é distância — é precisão.

**Ritmo:** Deliberado e espaçado — muito espaço negativo, ritmo lento de leitura. Elementos aparecem com intenção, não em cascata. Hierarquia clara que o olho segue sem esforço.

**Profundidade:** Alta — layering de elementos, uso de transparência controlada, fundos com gradiente sutil de profundidade. Interface que parece ter volume, não plana.

## Universo Estético

**O que AXIS É visualmente:**
- Salas de operações de centros de dados tier-4
- Terminal Bloomberg com o design de um produto de 2025
- Gráficos de dados da NASA — precisos, densos, sem decoração
- Tipografia editorial de jornais financeiros europeus premium (FT, Neue Zürcher)
- Materiais: titânio, vidro fosco, fibra de carbono, ouro mate

**O que AXIS NUNCA é visualmente:**
- Gradientes purple-to-pink de startup SaaS
- Ícones coloridos e amigáveis de "produto para todos"
- Backgrounds brancos com pontos de cor
- Imagens de stock com pessoas sorrindo em frente a laptops
- Tipografia Sans-serif genérica como Inter ou Roboto
- Qualquer elemento "cute" ou que tente "humanizar" em excesso
- Animações bounce ou elementos que "pulam"

## Referências que Informaram

**Movimento:** Swiss International Typographic Style (anos 1950–70) — grid rígido, hierarquia tipográfica, funcionalidade acima de ornamento

**Campo:** Visualização científica de dados — NASA data visualization guidelines, cartografia topográfica militar

**Período:** Era dourada do modernismo industrial — funcionalismo europeu, design de instrumentos de precisão

**Digital:** Linear, Vercel dark mode, GitHub dark mode — dark interfaces com extrema atenção à hierarquia

## Instruções para Agentes

**Para Chroma (cores):**
Base: azul profundo #0A1628 como dominante total. Grafite #1C2B3A para superfícies secundárias. Ouro #C9A84C como único acento quente — usar com extrema moderação (máximo 10% da composição). Branco #F5F7FA para texto principal. Nunca usar cores brilhantes ou saturadas além do ouro.

**Para Typo:**
Família principal: Serif editorial de alta qualidade (Canela, GT Sectra, ou Tiempos — preferir paid fonts que transmitem autoridade). Família secundária: Mono para dados e números (JetBrains Mono ou Commit Mono). Nunca usar Inter ou Roboto como primária.

**Para Mark:**
Símbolo deve derivar da metáfora de "eixo" — geométrico, preciso, sem ornamento. Considerar: intersecção de linhas formando um cross/axis, ou forma que sugira coordenadas matemáticas. Absolutamente sem símbolo de gráfico de barras ou bullish/bearish.
