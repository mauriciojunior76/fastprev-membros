# Checklist de Coerência da Marca

Use para validar qualquer peça antes de entregar.

## Checklist Visual

**Logo:**
- [ ] Versão correta para o fundo (positivo/negativo/branco/preto)
- [ ] Área de respiro respeitada em todos os lados
- [ ] Tamanho mínimo respeitado
- [ ] Logo não distorcido, não rotacionado, não com efeitos

**Cores:**
- [ ] Apenas cores do sistema (verificar HEX nos tokens)
- [ ] Contraste de texto: mínimo 4.5:1 (WCAG AA)
- [ ] Cores em fundos coloridos — versão correta do logo
- [ ] Combinações de cores aprovadas (não inventar novas)

**Tipografia:**
- [ ] Apenas famílias aprovadas (verificar typography-system.md)
- [ ] Pesos dentro dos aprovados
- [ ] Hierarquia respeitada (não inverter tamanhos)
- [ ] Line-height e letter-spacing conforme escala
- [ ] Nunca mais de 2 famílias na mesma peça

**Elementos Gráficos:**
- [ ] Apenas elements aprovados em pattern-library.md
- [ ] Opacidade dentro do range aprovado
- [ ] Grafismos não competem com o logo
- [ ] Composição respeita hierarquia visual

## Checklist de Linguagem

**Tom de voz:**
- [ ] Linguagem usa o vocabulário aprovado
- [ ] Sem palavras proibidas listadas em brand-voice.md
- [ ] Tom alinhado com o arquétipo (verificar archetypes.md)
- [ ] Sem genéricos corporativos ("inovador", "disruptivo", "único")

**Texto:**
- [ ] Headline usa a linguagem da marca
- [ ] CTA é direto e coerente com a promessa
- [ ] Nenhuma promessa contraditória com brand-strategy.md

## Checklist de Entrega

**Formatos:**
- [ ] PNG em resolução adequada (mínimo 2x para digital)
- [ ] SVG para logo e isotipo
- [ ] PDF para documentos

**Nomenclatura de arquivos:**
- [ ] Padrão: `{marca}-{tipo}-{variação}.{ext}`
- [ ] Sem espaços, sem acentos nos nomes
