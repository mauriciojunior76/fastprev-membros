# Checklist de Validação Estratégica

Verificar coerência da estratégia antes de avançar para Fase 2.

## Tese de Posicionamento

- [ ] Tem 15–25 palavras (não mais, não menos)
- [ ] Especifica para quem (ICP)
- [ ] Especifica o que é diferente (mecanismo único)
- [ ] Especifica a consequência (transformação)
- [ ] Exclui alguém — se serve a todos, não posiciona
- [ ] Sem: "inovador", "disruptivo", "único no mercado"

## ICP

- [ ] Definido por atitudes e crenças (não por faixa etária)
- [ ] Inclui o que valoriza profundamente
- [ ] Inclui o que detesta ver em marcas da categoria
- [ ] Inclui como toma decisão de compra

## Anti-Público

- [ ] Específico (não "pessoas que não precisam do produto")
- [ ] Justificado (por que a marca não serve este grupo)

## Pilares de Percepção

- [ ] 3–5 pilares (não mais)
- [ ] Cada pilar tem nome + definição + exemplo de manifestação
- [ ] Pilares são verificáveis na prática
- [ ] Nenhum pilar é genérico ("qualidade", "confiança" sem qualificação)

## Arquétipo

- [ ] Primário + secundário definidos
- [ ] Combinação é única e específica para esta marca
- [ ] Sombra documentada
- [ ] Tom de voz derivado do arquétipo é verificável
