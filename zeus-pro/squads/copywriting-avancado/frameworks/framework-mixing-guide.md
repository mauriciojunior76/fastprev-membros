# GUIA DE COMBINAÇÃO DE FRAMEWORKS

## STATUS: TIER 1 — consultar antes de escolher framework

Ter 10 frameworks é poder. Usar dois errados juntos é ruído.
Este guia define QUANDO combinar, QUAIS combinar e COMO sobrepor sem perder foco.

---

## REGRA CENTRAL

Uma copy usa UM framework dominante.
Pode usar um framework de suporte, mas nunca dois dominantes.
Três frameworks numa mesma copy = cozinha de 3 chefs = prato sem identidade.

---

## MAPA DE COMBINAÇÕES APROVADAS

### COMBINAÇÃO 1: ARENA + VMC (a mais versátil)

Quando usar: qualquer copy longa (LP, email, VSL) para público nível 2-3.
Como combinar: ARENA define a estrutura dos 7 passos. VMC define qual emoção domina cada passo.

```
ARENA Passo 1 (gancho)    → VMC define: é dor ou desejo que abre?
ARENA Passo 2 (cena real) → VMC mantém: a cena é de sofrimento ou de aspiração?
ARENA Passo 3 (diagnóstico) → VMC aprofunda a emoção escolhida
ARENA Passos 4-7          → VMC garante consistência emocional até o CTA
```

Resultado: copy com estrutura sólida E coerência emocional. O leitor sente que a copy "entende ele de verdade".

---

### COMBINAÇÃO 2: COPY KILLER FORMULA + SEXY CANVAS

Quando usar: anúncios Meta Ads cold para público nível 1-2.
Como combinar: SexyCanvas identifica o gatilho emocional primitivo ANTES. CopyKiller Formula estrutura a copy em cima desse gatilho.

```
PASSO 0 (SexyCanvas): identificar qual dos 8 gatilhos domina este público neste contexto
  → GANANCIA? → copy focada em ROI, cálculo de valor, retorno
  → PREGUICA? → copy focada em atalho, 8 minutos, sem consultor
  → VAIDADE?  → copy focada em status, reconhecimento, "você sabe demais"
  → IRA?      → copy focada em confronto, injustiça, "seu conhecimento te custando"

PASSO 1 (CopyKiller): VMC = gatilho identificado pelo SexyCanvas
PASSO 2 (CopyKiller): gancho que ativa o gatilho com máxima intensidade
PASSO 3 (CopyKiller): crença falsa que bloqueia o gatilho de virar ação
```

Resultado: copy que vai direto no ponto emocional certo, sem adivinhar. O gancho não é genérico porque foi escolhido com base no gatilho real do público.

---

### COMBINAÇÃO 3: RUSSELL BRUNSON FUNNELS + PASTOR (emails)

Quando usar: sequência de emails para lead frio que virou morno.
Como combinar: Russell Brunson define a SEQUÊNCIA e a lógica de cada email. PASTOR define a ESTRUTURA INTERNA de cada email.

```
Email 1 (Big Domino): PASTOR — Problema inicial + Amplify + Story (epiphany bridge pessoal)
Email 2 (Crença Falsa 1): PASTOR — Problema da crença + Amplify + Story (caso de aluno)
Email 3 (Crença Falsa 2): PASTOR — Problema da objeção + Amplify + Testemunho verificável
Email 4 (Oferta): PASTOR completo — Offer + Response final
```

Resultado: sequência com lógica de funil (Russell Brunson) E emails que leem fluido e convertem individualmente (PASTOR).

---

### COMBINAÇÃO 4: HORMOZI OFFER + AIDA (landing page)

Quando usar: LP de produto LT (R$67) ou página de captura HT.
Como combinar: Hormozi define OS ELEMENTOS da oferta. AIDA define A ORDEM de apresentação.

```
A (Attention):   Gancho + problema central — ainda sem revelar a oferta
I (Interest):    Mecanismo único + prova + como funciona — a curiosidade sobre o produto
D (Desire):      Stack completo Hormozi — o que está incluído, o valor de cada item
A (Action):      Preço real vs valor percebido + garantia + CTA único
```

Resultado: página que não só tem oferta boa (Hormozi) mas apresenta na ordem certa para converter (AIDA).

---

### COMBINAÇÃO 5: PAS + HORMOZI OFFER (anúncio curto)

Quando usar: copy de anúncio de 150-300 chars para público nível 2-3.
Como combinar: PAS comprime o argumento. Hormozi garante que a solução tem peso.

```
P (Problem):  1 frase de dor específica (máx 40 chars)
A (Agitate):  1 frase que amplifica o custo do problema
S (Solution): oferta Hormozi comprimida: produto + resultado + preço + garantia em 1 linha
```

Resultado: copy curta com argumento completo. Não é copy rasa, é copy densa.

## COMBINAÇÕES PROIBIDAS

| Combinação | Por que proibir |
|------------|----------------|
| AIDA + PAS | Estruturas concorrentes. AIDA abre com atenção, PAS abre com dor. Uma vai matar a outra. |
| SexyCanvas + VMC como dominantes | Os dois atacam emoção. Um escolhe o gatilho, o outro executa. Nunca dois escolhendo ao mesmo tempo. |
| Russell Brunson + ARENA como dominantes | Os dois têm 7 passos e lógica de sequência. Dois frameworks de estrutura = paralisia. |
| PASTOR + ARENA | PASTOR é para email (1 argumento linear). ARENA é para copy multi-bloco. Misturar cria copy confusa. |

---

## MATRIZ DE ESCOLHA RÁPIDA

Antes de escolher framework, responder 3 perguntas:

1. Canal: qual é? (anúncio / email / WA / LP / roteiro)
2. Tamanho: curto (<300 chars) / médio (300-800) / longo (800+)
3. Nível de consciência: 1 / 2 / 3 / 4 / 5

| Canal + Tamanho | Nível 1-2 | Nível 3-4 | Nível 5 |
|-----------------|-----------|-----------|---------|
| Anúncio curto | PAS + SexyCanvas | COPY KILLER + VMC | AIDA comprimido |
| Anúncio longo | ARENA + VMC | COPY KILLER + HORMOZI | HORMOZI puro |
| Email único | PAS | PASTOR | AIDA |
| Sequência email | RUSSELL + PASTOR | RUSSELL + PASTOR | PASTOR acelerado |
| Landing page | ARENA + HORMOZI | AIDA + HORMOZI | HORMOZI puro |
| WhatsApp | PAS comprimido | PAS comprimido | Direto (sem framework) |
| Roteiro reels | PAS (3 blocos, 30s) | COPY KILLER visual | Oferta direta |

---

## COMO USAR ESTE GUIA

1. Copy Chief recebe o briefing
2. Consulta a Matriz de Escolha Rápida (canal + tamanho + nível de consciência)
3. Identifica o framework dominante + o de suporte (se aplicável)
4. Recruta os agentes baseado nos frameworks escolhidos (não baseado em hábito)
5. Briefing para os agentes inclui: "framework dominante: X, de suporte: Y"

Resultado: agentes trabalham com direção clara, não improvisam combinação.
