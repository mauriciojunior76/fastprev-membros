# FRAMEWORK: COPY KILLER FORMULA

## A Fórmula

```
VMC (por que compram)
+ Gancho (como ativar a emoção)
+ Crença Falsa Removida (por que agora é possível)
= Conversão
```

## Por Que Funciona

A maioria das copies falha em um destes pontos:
- Atacam a cabeça sem atacar a emoção real (VMC errada)
- Têm um gancho genérico que não ativa ninguém (gancho fraco)
- Não removem o bloqueio que impede a ação (crença falsa presente)

Copy Killer força o diagnóstico dos três antes de escrever uma palavra.

## Aplicação Passo a Passo

### Passo 1: Identificar a VMC

Usar o framework VMC.md para diagnosticar.
Escolher UMA VMC. A mais forte para aquele público/canal.

### Passo 2: Escolher o Gancho

O gancho precisa ATIVAR a VMC escolhida.

| VMC | Tipo de gancho ideal |
|-----|---------------------|
| Dificuldade | Diagnóstico ou Revelação |
| Medo | Prova Social ou Cálculo de Valor |
| Urgência | Contraste ou Número Inesperado |
| Inveja | Prova Social ou Validação + Confronto |
| Identidade | Validação + Confronto ou Sonho |
| Tempo | Sofrimento ou Contraste |

### Passo 3: Identificar e Remover a Crença Falsa

A crença falsa é o "mas" que o público diz internamente.
Ela impede a ação mesmo quando a pessoa quer comprar.

Crenças falsas mais comuns para o Agente Arquiteto:

| Crença falsa | Como remover na copy |
|-------------|---------------------|
| "Preciso gravar aulas primeiro" | "Você não precisa de curso gravado para ter mentoria" |
| "Preciso de audiência grande" | "um cliente do exemplo não tinha audiência e estruturou em 8 minutos" |
| "É complicado demais pra mim" | "8 minutos. Você fala, a IA organiza." |
| "R$67 é investimento que não posso dar" | "R$67 que vira R$2.997. A conta não fecha a seu favor?" |
| "Já tentei e não funcionou" | "Não é o seu método que falhou. É a falta de estrutura." |

### Passo 4: Montar a Copy

Com os três elementos definidos, montar seguindo ARENA ou PASTOR:

```
[Gancho que ativa a VMC]
[Desenvolvimento da dor/desejo — a VMC expandida]
[Remoção da crença falsa — o "mas" que impede]
[Mecanismo — como o produto resolve]
[Prova — que já funcionou para outros]
[CTA — único, direto]
```

## Checklist Copy Killer

Antes de entregar qualquer copy, verificar:
- [ ] VMC foi identificada explicitamente?
- [ ] O gancho ativa especificamente essa VMC?
- [ ] A crença falsa principal foi identificada e removida dentro da copy?
- [ ] A copy ataca UMA VMC, não três ao mesmo tempo?
- [ ] O CTA está alinhado com a VMC (fuga ou aproximação)?
