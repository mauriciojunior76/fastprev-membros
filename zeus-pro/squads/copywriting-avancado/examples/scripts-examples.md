# EXEMPLOS — SCRIPTS E ROTEIROS

## TIPO 1 — ROTEIRO REELS/SHORTS (30-60 segundos)

### Gancho de Sofrimento (0-5s)
```
"Você tem experiência de sobra para cobrar R$5k de mentoria."
```

### Agitação (5-20s)
```
"Mas sem estrutura, você vende consulta por hora.
E o cliente não enxerga o valor do conjunto que você entrega.
Resultado: você cobra R$200 a hora enquanto
especialistas menos experientes cobram R$2.997 por sessão."
```

### Solução (20-30s)
```
"O Agente Arquiteto organiza tudo em 8 minutos.
Estrutura, preço e script de venda.
Link aqui."
```

## TIPO 2 — ROTEIRO DEPOIMENTO/CASO REAL (60-90 segundos)

### Estrutura
```
[0-10s] SITUAÇÃO ANTES — relatable, não glamorosa
[10-30s] O PROBLEMA — específico, com consequência
[30-50s] O QUE MUDOU — a ferramenta/produto/decisão
[50-70s] O RESULTADO — específico e verificável
[70-90s] O QUE ELE DIRIA — CTA emocional
```

### Exemplo preenchido
```
[0-10s]
"Fui nutricionista por 7 anos.
Tinha clientes, consultório, expertise.
Mas faturava variável todo mês."

[10-30s]
"Queria criar mentoria para nutricionistas.
Mas nunca sabia por onde começar.
Ficava mudando o formato.
Tinha medo de cobrar muito."

[30-50s]
"Um dia usei o Agente Arquiteto.
8 minutos depois tinha estrutura completa.
Preço calculado: R$3.497.
Script de como vender."

[50-70s]
"No primeiro mês com a mentoria estruturada
fechei 2 mentorandas.
R$6.994 recorrentes.
Mais do que em 3 meses de consultório."

[70-90s]
"Se você é especialista e ainda não tem mentoria,
a estrutura não é o problema mais.
Você só precisa do modelo certo.
Link aqui."
```

## TIPO 3 — SCRIPT WEBINAR/APRESENTAÇÃO AO VIVO

### Abertura (5 minutos)
```
"Nos próximos [X] minutos, vou te mostrar
como especialistas estão estruturando mentorias
que vendem por R$5k-R$15k por cliente,
sem gravar um curso, sem ter audiência grande,
sem meses de planejamento.

Antes de começar: quem está aqui é especialista
com experiência real, certo?
Nutricionista, coach, médico, advogado, contador,
alguém que tem conhecimento que ajuda as pessoas.

Então isso aqui é pra você.

Mas antes do método, preciso te mostrar
por que 90% dos especialistas nunca lançam a mentoria.
Não é por falta de conhecimento."
```

### Quebra de Crença (10 minutos)
```
"A maioria acredita que o problema é falta de tempo.
Ou falta de audiência. Ou falta de dinheiro para tráfego.

Mas se você olhar para especialistas que vendem por R$5k,
vai perceber que muitos têm audiência menor que a sua.
Muitos têm menos experiência que você.
Muitos começaram sem tráfego.

O que eles têm que você não tem?

Uma estrutura que transforma conhecimento em oferta vendável."
```

### Transição para Oferta
```
"Agora que você entende o princípio,
deixa eu te mostrar como implementar isso.

Existe um caminho que leva 8 minutos.
E um que leva 6 meses.

O de 8 minutos usa IA para organizar tudo.
O de 6 meses usa planilha, tentativa e erro.

Eu vou te mostrar o caminho de 8 minutos."
```

## TIPO 4 — SCRIPT DE VENDA 1:1 (Call de diagnóstico)

### Abertura (5 minutos)
```
"Antes de te apresentar qualquer coisa,
quero entender onde você está agora.

Me conta: você tem alguma mentoria no ar,
ou ainda está estruturando?

[ouvir]

E o que está travando?

[ouvir]

Há quanto tempo você está com esse bloqueio?"
```

### Diagnóstico (10 minutos)
```
"Se eu entendi bem, você tem [X anos] de experiência,
atende clientes como [perfil],
e o maior obstáculo para ter a mentoria no ar é [obstáculo].

Isso está correto?

[confirmar]

Deixa eu te perguntar uma coisa:
Se esse obstáculo não existisse,
qual seria o próximo passo que você daria?"
```

### Apresentação de Solução (10 minutos)
```
"O que você descreveu é exatamente o que vejo
em especialistas que ainda não estruturaram.

Não é falta de conteúdo.
É falta de um modelo que organize.

A sua mentoria resolve isso em [X semanas].
A gente vai [descrição da transformação].

Posso te mostrar como funciona?"
```

## REGRAS DE SCRIPT

1. Nunca ler o script (roteiro de Reels pode ser semi-decorado, nunca lido)
2. Falar como especialista, não como vendedor
3. Prova social sempre com nome real e resultado específico
4. CTA uma vez só (no final, depois que o desejo foi criado)
5. Roteiros de até 30s: script mínimo, espaço para improviso natural
6. Roteiros de 1min+: estrutura clara, improviso nas transições
