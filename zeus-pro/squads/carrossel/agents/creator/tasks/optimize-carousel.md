## Process

1. Revisar o carrossel criado na task anterior
2. Verificar e otimizar cada slide:
   a. Headline é impactante o suficiente? Pode ser mais direto?
   b. Supporting text tem dados concretos? Pode adicionar número ou exemplo?
   c. Transição entre slides é fluida? O leitor quer passar para o próximo?
3. Otimizar a legenda:
   a. Hook dos 125 chars: testar 2 variações, escolher a mais forte
   b. Corpo: garantir quebras de linha para legibilidade
   c. CTA: é específico o suficiente? (ex: "comenta SIM" vs "comenta")
4. Revisar hashtags: remover genéricas demais, adicionar nicho se faltou
5. Verificar ortografia e acentuação (regra marcial: português perfeito)
6. Output final é o carrossel completo otimizado no mesmo formato

## Output Format

Mesmo formato da task create-carousel, com as otimizações aplicadas.
Adicionar ao final:

```
=== OTIMIZAÇÕES APLICADAS ===
- [Lista de mudanças feitas]
```

## Output Example

```
=== OTIMIZAÇÕES APLICADAS ===
- Slide 1: headline reescrito de 22 para 12 palavras (mais impacto)
- Slide 4: adicionado dado de 40% redução no ciclo de vendas
- Slide 7: expandido de 32 para 45 palavras
- Legenda: hook reescrito com número no início (mais clicável)
- Hashtags: removidas 2 genéricas, adicionadas 2 de nicho mentoria
- Acentuação corrigida em 3 palavras
```

## Quality Criteria

- Todas as otimizações listadas e justificadas
- Nenhum slide fora da faixa 40-80 palavras após otimização
- Hook da legenda mais forte que a versão original
- Ortografia e acentuação 100% corretas
- Pelo menos 3 otimizações aplicadas

## Veto Conditions

- Zero otimizações: algo está errado, revisar com mais critério
- Otimização que piora o conteúdo (reduz palavras abaixo de 40): reverter
