# Checklist Pre-Evento

Executar 48h ANTES do inicio do evento.
Todos os itens devem ser aprovados para prosseguir.

---

## Itens Obrigatorios

- [ ] Confirmacao de presenca enviada (email + WhatsApp)
- [ ] Lembretes inteligentes prontos (beneficio concreto, NAO "faltam X dias")
- [ ] Links revisados (pagina evento, checkout, oferta, bonus)
- [ ] Slides/apresentacao prontos e revisados
- [ ] Pitch ensaiado (3 etapas: ancoragem D1 10:30, oferta D2 11:30, abertura D2 16:40)
- [ ] Bonus aprovados (escalonados, cada um responde objecao real)
- [ ] Regras comerciais claras (limites de boleto, cashback, condicoes)
- [ ] Equipe de suporte pronta (moderadores, suporte tecnico)
- [ ] Paginas da oferta revisadas (checkout, order bumps, upsell)
- [ ] Monitoramento do ao vivo configurado (metricas em tempo real)

## Validacoes Extras

- [ ] Estrutura 80/20 confirmada (80% conteudo, 20% pitch)
- [ ] Regra de ouro verificada (conteudo retorna apos pitch final)
- [ ] Seeding mapeado nos blocos corretos
- [ ] Curva de energia validada (inicio alto, sustenta, pico no pitch)
- [ ] Scripts WhatsApp de lembrete de vespera prontos
- [ ] Time comercial briefado (11 toques, nova razao por toque)
- [ ] Gravacao configurada (se aplicavel)
- [ ] Sala VIP planejada (se aplicavel)
