# Checklist Pre-Captacao

Executar ANTES de iniciar a captacao de ingressos.
Todos os itens devem ser aprovados para prosseguir.

---

## Itens Obrigatorios

- [ ] Promessa central com imagem mental clara (formula: tempo + acao + entrega visivel)
- [ ] Headline de execucao (responde: o que, quanto tempo, resultado, por que agora)
- [ ] Pagina de vendas com sequencia correta (12 secoes na ordem)
- [ ] Lote inicial atraente (R$19-49, urgencia clara)
- [ ] Plano de criativos C0 a C4 definido com briefings
- [ ] Setup de pixel e eventos de conversao configurados
- [ ] Checkout testado (fluxo completo, pagamento, confirmacao)
- [ ] CRM pronto (pipeline, segmentacao, automacoes de welcome)
- [ ] Equipe alinhada (9 funcoes, responsabilidades claras)
- [ ] Metas por fase definidas (ingressos, comparecimento, conversao, faturamento)

## Validacoes Extras

- [ ] Verbos proibidos verificados (aprender, descobrir, faturar, desbloquear, conquistar, segredos)
- [ ] Connect rate testado (pagina carrega rapido, fluxo limpo anuncio > LP)
- [ ] UTMs configurados por origem/campanha
- [ ] Scripts de WhatsApp de welcome prontos
- [ ] Calendario macro do lancamento aprovado
