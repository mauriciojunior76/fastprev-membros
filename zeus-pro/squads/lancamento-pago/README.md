# Launch Paid Squad - Lancamento Pago (Metodologia Baldan)

Squad de 41 agentes especializados em lancamento pago.

## Ativacao

```
@launch-paid           # Ativa o launch-chief (orquestrador)
@launch-paid:agente    # Ativa agente especifico
```

## Comandos

- `*start-launch` - Inicia pipeline completo do lancamento
- `*diagnose` - Diagnostica problemas por etapa
- `*daily-review` - Revisao diaria com 5 perguntas
- `*pre-check` - Checklist pre-captacao
- `*review-copy` - Ciclo de revisao de copy

## Pipeline

```
Pesquisa > Promessa > Big Idea > Narrativa > Plano Mestre
    > Oferta + Ingresso + Bonus + Upgrades
    > Headlines > Copy Pagina > Emails + WhatsApp + Ads
    > Curriculum > Evento > Pitch > Seeding
    > Criativos C0-C4 + Remarketing
    > Comercial + Follow-up + Lives + VIP
    > Metricas + Checklists + CRM + Equipe
    > GATE FINAL > ENTREGA
```

## Regras da Metodologia

1. Promessa: tempo curto + acao pratica + entrega visivel
2. Verbos proibidos: aprender, descobrir, faturar, desbloquear, conquistar, segredos
3. Evento: 2 dias, 80% conteudo, 20% pitch, mao na massa
4. Pitch: 3 etapas (ancoragem D1 10:30, oferta D2 11:30, abertura D2 16:40)
5. Regra de ouro: conteudo retorna APOS pitch final
6. Ingresso R$19-49 como qualificador
7. Comercial: ate 11 toques, cada um com razao nova
8. Bonus escalonados que respondem objecoes reais
9. Single Shot: aparece uma vez, depois acaba
10. Lembrete inteligente: beneficio, nao contagem regressiva
11. Modelo simples vence modelo complexo
