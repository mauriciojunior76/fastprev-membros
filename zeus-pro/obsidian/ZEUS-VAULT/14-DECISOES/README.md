# 14-DECISOES: Decisões

## O que guardar aqui

Registro de decisão: o que foi decidido, quando, por quê, o que se esperava e quando revisar.

## O que NÃO guardar aqui

Decisão sem motivo. O motivo é o que permite avaliar depois se a decisão foi boa.

## Quando atualizar

A cada decisão relevante, e na data de revisão marcada.

## Quem usa esta informação

Planejamento e decisão, e qualquer squad diante de escolha parecida.

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#decisoes` para
agrupar por tema dentro da pasta.
