# 05-POSICIONAMENTO: Posicionamento

## O que guardar aqui

Como você quer ser percebido, sua autoridade, seu método, o que você promete e o que você nunca promete.

## O que NÃO guardar aqui

Aspiração sem lastro. Posicionamento precisa de prova real.

## Quando atualizar

Quando você mudar de patamar ou de público.

## Quem usa esta informação

Copywriting, branding, apresentações, planejamento.

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#posicionamento` para
agrupar por tema dentro da pasta.
