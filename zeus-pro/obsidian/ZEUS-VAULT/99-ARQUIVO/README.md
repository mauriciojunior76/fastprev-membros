# 99-ARQUIVO: Arquivo

## O que guardar aqui

O que saiu de circulação mas não pode ser perdido: projeto encerrado, produto descontinuado, decisão superada, versão antiga.

## O que NÃO guardar aqui

Nada é proibido aqui. Esta pasta existe justamente para não precisar apagar nada.

## Quando atualizar

Quando algo sair de uso. Mova, não apague.

## Quem usa esta informação

Raramente. Só quando você perguntar do passado.

## Nível de sensibilidade

igual ao original

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
igual ao original
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#arquivo` para
agrupar por tema dentro da pasta.
