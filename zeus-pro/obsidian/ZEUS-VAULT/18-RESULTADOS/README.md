# 18-RESULTADOS: Resultados

## O que guardar aqui

O que foi entregue e o que deu: peça publicada, campanha rodada, produto lançado, com o número real que resultou.

## O que NÃO guardar aqui

Estimativa apresentada como resultado. Aqui só entra o que aconteceu de verdade.

## Quando atualizar

Depois de cada entrega, quando o resultado aparecer.

## Quem usa esta informação

Todos. É o que ensina o que funciona no seu caso específico.

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#resultados` para
agrupar por tema dentro da pasta.
