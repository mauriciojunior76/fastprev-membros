# 13-AGENTES: Agentes

## O que guardar aqui

Documentação dos agentes individuais: papel, autoridade, o que sempre faz e o que nunca faz.

## O que NÃO guardar aqui

Prompt completo. Ele vive no repositório.

## Quando atualizar

Quando um agente for criado ou ajustado.

## Quem usa esta informação

O orquestrador e os leads de squad.

## Nível de sensibilidade

normal
