# 15-DIARIOS: Diários

## O que guardar aqui

O diário de bordo: o que aconteceu, o que foi decidido, o que resultou, o que ficou em aberto.

## O que NÃO guardar aqui

Diário de dia comum sem nada relevante. Escreva quando houver o que registrar.

## Quando atualizar

Nos dias que merecem registro.

## Quem usa esta informação

Todos, para entender a evolução e detectar problema que se repete.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
camada: histórica
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#diarios` para
agrupar por tema dentro da pasta.
