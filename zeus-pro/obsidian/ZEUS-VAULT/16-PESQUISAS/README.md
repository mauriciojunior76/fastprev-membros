# 16-PESQUISAS: Pesquisas

## O que guardar aqui

Resultado de pesquisa: concorrência, mercado, ferramenta, tendência. Sempre com fonte e data.

## O que NÃO guardar aqui

Conclusão sem fonte. Pesquisa sem origem é opinião disfarçada.

## Quando atualizar

A cada pesquisa. Marque a data: pesquisa envelhece.

## Quem usa esta informação

Pesquisa, planejamento, tráfego, produtos de entrada.

## Nível de sensibilidade

normal
