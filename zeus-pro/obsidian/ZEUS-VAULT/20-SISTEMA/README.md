# 20-SISTEMA: Sistema

## O que guardar aqui

Como o ZEUS trabalha para você: preferências de formato, nível de autonomia, regras que você criou, o que ele aprendeu a fazer diferente.

## O que NÃO guardar aqui

Configuração técnica do repositório. Isso vive em `.claude/`.

## Quando atualizar

Quando você corrigir o comportamento dele.

## Quem usa esta informação

O próprio ZEUS, em toda sessão.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
camada: preferências
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#sistema` para
agrupar por tema dentro da pasta.
