# 09-PROCESSOS: Processos

## O que guardar aqui

Como as coisas são feitas: passo a passo, quem faz, com qual ferramenta, em quanto tempo.

## O que NÃO guardar aqui

Processo idealizado que ninguém segue. Documente o processo REAL primeiro.

## Quando atualizar

Quando o processo mudar de verdade na prática.

## Quem usa esta informação

Automação, planejamento, desenvolvimento.

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#processos` para
agrupar por tema dentro da pasta.
