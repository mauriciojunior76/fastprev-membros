# 03-PRODUTOS: Produtos

## O que guardar aqui

Um arquivo por produto ou serviço: o que é, preço, para quem, transformação, objeções, provas, garantia, status.

## O que NÃO guardar aqui

Dois produtos no mesmo arquivo. Eles mudam em ritmos diferentes.

## Quando atualizar

Sempre que mudar preço, oferta, entrega ou status.

## Quem usa esta informação

Copywriting, produtos de entrada, tráfego, apresentações, ebooks.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
camada: comercial
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#produtos` para
agrupar por tema dentro da pasta.
