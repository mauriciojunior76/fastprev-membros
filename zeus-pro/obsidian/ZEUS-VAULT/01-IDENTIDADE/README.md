# 01-IDENTIDADE: Identidade

## O que guardar aqui

Quem você é profissionalmente: formação, especialidades, história, conquistas, o que te tornou bom no que faz.

## O que NÃO guardar aqui

Dado pessoal que não afeta o trabalho (documentos, saúde, família).

## Quando atualizar

Raramente. Quando você conquistar algo relevante ou mudar de área.

## Quem usa esta informação

Copywriting, branding, posicionamento e qualquer squad que precise falar em seu nome.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.

criado_em: AAAA-MM-DD

---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#identidade` para
agrupar por tema dentro da pasta.
