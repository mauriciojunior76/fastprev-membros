# 00-INICIO: Início

## O que guardar aqui

O painel de entrada da sua Vault. Um arquivo `Home.md` com links para o que você mais acessa, o retrato atual do negócio e os projetos ativos.

## O que NÃO guardar aqui

Conteúdo. Esta pasta só aponta, nunca guarda.

## Quando atualizar

Quando mudar o que você acessa toda semana.

## Quem usa esta informação

Todos. É a primeira coisa que o ZEUS lê quando você pergunta "como estão as coisas".

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#inicio` para
agrupar por tema dentro da pasta.
