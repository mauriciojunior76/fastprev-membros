# 04-PUBLICOS: Públicos

## O que guardar aqui

Quem você atende: perfil, momento de vida, dores, desejos, medos, objeções, crenças, e a linguagem literal que essas pessoas usam.

## O que NÃO guardar aqui

Dado de cliente identificável. Aqui é perfil, não pessoa.

## Quando atualizar

Sempre que você ouvir uma frase de cliente que revele algo novo.

## Quem usa esta informação

Copywriting, tráfego, produtos de entrada, pesquisa.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
camada: público
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#publicos` para
agrupar por tema dentro da pasta.
