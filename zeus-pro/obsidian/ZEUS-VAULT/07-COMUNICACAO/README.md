# 07-COMUNICACAO: Comunicação

## O que guardar aqui

Como você escreve e fala: tom, formalidade, palavras que usa, palavras proibidas, uso de emoji e humor, e AMOSTRAS REAIS de texto seu.

## O que NÃO guardar aqui

Descrição vaga do tipo "tom profissional mas descontraído". Isso não ensina nada. Amostra ensina.

## Quando atualizar

Sempre que você corrigir um texto do ZEUS. A correção é a informação mais valiosa aqui.

## Quem usa esta informação

Todos os que escrevem qualquer coisa.

## Nível de sensibilidade

normal

## Frontmatter padrão desta pasta

```yaml
---
nome: nome-do-arquivo
descrição: Uma linha clara.
camada: comunicação
tipo: declaração
origem: de onde veio
confiança: alta
sensibilidade: normal
responsável: usuário
status: ativo
criado_em: AAAA-MM-DD
atualizado_em: AAAA-MM-DD
validade: null
relacionados: []
---
```

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#comunicacao` para
agrupar por tema dentro da pasta.
