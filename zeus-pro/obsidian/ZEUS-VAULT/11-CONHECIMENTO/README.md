# 11-CONHECIMENTO: Conhecimento

## O que guardar aqui

O que você aprendeu de fontes externas: livros, cursos, artigos, aulas. Cada item vira um dossiê com os conceitos ancorados na fonte.

## O que NÃO guardar aqui

Cópia integral de material protegido por direito autoral. Guarde o entendimento e a referência, não o texto inteiro.

## Quando atualizar

A cada material novo ingerido.

## Quem usa esta informação

Pesquisa, conhecimento, e o squad do tema estudado.

## Nível de sensibilidade

normal

## Como relacionar com outras notas

Use `[[nome-do-arquivo]]` para ligar esta nota a outras. Link para arquivo
que ainda não existe é aceitável: marca o que vale escrever depois.

Use tags no formato `#conhecimento` para
agrupar por tema dentro da pasta.
