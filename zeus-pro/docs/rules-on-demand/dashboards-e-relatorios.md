# Painéis e relatórios

Este documento mostra o que o Zeus consegue montar para você enxergar os seus números: painéis de acompanhamento, controle de dados e integrações, e relatório de tráfego. Leia quando quiser parar de olhar planilha solta e passar a ter uma visão única do que está acontecendo.

## 1. Painel de acompanhamento

É uma página só sua, publicada no seu endereço, que mostra os números do seu negócio atualizados. Serve para você bater o olho de manhã e saber como está, sem abrir cinco ferramentas diferentes.

O que costuma entrar num painel:

- quanto foi investido no período e quanto entrou;
- quantas pessoas chegaram e quantas viraram conversa de verdade;
- o custo de cada etapa do seu funil;
- a evolução dia a dia, para você ver a linha subindo ou caindo.

Como pedir:

```
monta um painel de acompanhamento com os números da minha
conta de anúncios dos últimos 30 dias, mostrando investimento,
pessoas que chegaram, conversas iniciadas e custo por conversa
```

```
adiciona no painel a comparação do mês atual com o mês passado
```

## 2. Controle de dados e integrações

É a parte de bastidor: onde os dados ficam guardados e como as ferramentas conversam entre si. Sem isso, cada número mora numa ilha e ninguém confere nada.

O que o Zeus organiza aqui:

- guardar em um lugar só os registros que hoje estão espalhados em planilha, formulário e caderno;
- ligar uma ferramenta na outra, para o dado passar sozinho de uma ponta a outra;
- avisar você quando alguma dessas ligações parar de funcionar, em vez de você descobrir semanas depois.

Como pedir:

```
organiza os meus dados de contatos num lugar só e me mostra
o que está duplicado ou faltando informação
```

```
liga o meu formulário no painel, para todo cadastro novo
aparecer lá sozinho
```

```
cria um aviso para mim caso pare de entrar cadastro novo
por mais de um dia
```

## 3. Relatório de tráfego

É a leitura do que aconteceu na sua verba de anúncios num período. Não é a exportação da plataforma: é a interpretação dela.

Como pedir:

```
me faz o relatório de tráfego da última semana
```

```
me explica por que o custo subiu na quinta e o que eu faço
a partir de segunda
```

## O princípio do relatório que se lê como conversa

Um relatório bom se lê como alguém sentando do seu lado e te contando o que houve. Não é uma parede de colunas para você decifrar sozinho.

A estrutura é sempre a mesma, em texto corrido:

1. O que aconteceu. Os fatos do período, em ordem, com os poucos números que realmente importam.
2. Por que aconteceu. A causa provável, dita com honestidade. Se a causa não é conhecida, o relatório diz que não é conhecida, em vez de inventar uma explicação bonita.
3. O que fazer agora. Uma ou duas ações concretas, com o que você vai olhar depois para saber se deu certo.

Planilha mostra o quê. Relatório explica o porquê e aponta o próximo passo. Se o que você recebeu não te ajuda a decidir nada, não era relatório, era exportação com capa nova.

## Todo número exibido vem de dado medido

Esta é a regra que sustenta tudo acima e não tem exceção.

1. Número em painel ou relatório vem de uma medição real, feita na fonte. Nunca de estimativa de cabeça, nunca de arredondamento de memória.
2. Quando um número é uma projeção, ele aparece escrito como projeção, com essa palavra do lado. Projeção é palpite bem fundamentado sobre o futuro, e misturar isso com o que já aconteceu é o jeito mais rápido de tomar decisão errada com confiança total.
3. Se o dado não existe ou está furado, o relatório diz que está furado e o que precisa ser arrumado. Espaço em branco honesto vale mais que número inventado.
4. Sempre que possível, o número vem com o período ao lado. "Custo de 42 reais" não quer dizer nada. "Custo de 42 reais por conversa, nos últimos 7 dias" quer dizer tudo.

Se você desconfiar de algum número, pergunte direto:

```
de onde saiu esse número? me mostra a fonte e o período
```

Essa pergunta deve ter resposta em qualquer momento. Se não tiver, o número não deveria estar lá.
