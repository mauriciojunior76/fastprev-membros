# Cruzar squads: como pedir trabalho grande

Não existe comando certo nem palavra mágica. Você fala como falaria com uma
pessoa. O que muda o resultado é dizer QUAL time você quer no trabalho, e,
quando o trabalho é grande, quais times entram em qual ordem.

## O pedido simples

Nomear o time já melhora muito a entrega, porque o ZEUS carrega o método
daquele domínio antes de começar:

> quero fazer um e-book, aciona o squad de e-books

> quero fazer um webinário, aciona o squad de webinário

> quero fazer uma página de produto de entrada, aciona o squad de páginas

## O pedido cruzado

Trabalho de verdade quase nunca é de um time só. Um carrossel tem texto e
tem arte. Um lançamento tem estratégia, texto e página. Quando você diz a
ordem, cada time faz a parte dele em cima da parte pronta do anterior, em vez
de um time só tentar fazer tudo com meia competência.

Exemplo de carrossel:

> nesse momento eu quero fazer um carrossel. Você vai cruzar: usa o squad de
> copy para fazer todos os textos desse carrossel e usa o squad de carrossel
> para fazer a arte visual

Exemplo de evento online:

> usa o squad de webinário para planejar o webinário, depois usa o squad de
> copy para reformular todos os textos e usa o squad de páginas para
> construir uma página profissional

## Combinações que funcionam bem

| Trabalho | Ordem dos times |
|---|---|
| Carrossel para rede social | copy, depois carrossel |
| E-book de verdade | copy, depois e-books, depois branding para o acabamento |
| Lançamento com verba | lançamento pago, depois copy, depois páginas, depois tráfego |
| Aula ou palestra | apresentações, depois copy para os títulos de slide |
| Vídeo de venda | copy para o roteiro, depois vídeo para o corte e a edição |
| Produto novo | produtos de entrada, depois páginas, depois tráfego |
| Painel de números | tráfego para a leitura, depois painel de dados para a tela |

## Quando o ZEUS diz que não pode

Às vezes a resposta é uma recusa. Em boa parte dos casos é falta de
configuração ou de permissão, não impossibilidade. Pergunte assim:

> o que eu preciso fazer para te dar acesso e autorização para você fazer
> isso?

Ele responde com a lista exata do que falta: uma chave, uma extensão do
navegador, uma pasta, uma permissão, um nível de autonomia mais alto. Se o
que falta for uma trava de segurança (dinheiro, publicação, envio, destruição
de dado), a resposta é uma confirmação sua na hora, e essa trava não sai.

## A regra por trás

Um time por vez, cada um no que sabe, na ordem em que o material nasce.
Pedido grande sem ordem vira entrega média. Pedido grande com ordem vira
entrega inteira.
